# outputs 구조 안내

현재 `outputs/`는 큰 묶음만 보이도록 정리했습니다.

- `baseline/`
  - 최근 2년 Binance `1m` baseline 연구 결과
- `paper_like/`
  - 논문 유사 `daily` / `weekly` 비교 결과
- `tick/`
  - 현재 active tick 연구 결과
- `legacy/`
  - 과거 exploratory 결과 보관
